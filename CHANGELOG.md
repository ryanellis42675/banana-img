# Changelog

All notable changes to Banana Img (banana-img) will be documented in this file.

## [0.1.0] - 2026-10-07

### Added
- Initial polyglot multi-language SDK release for Banana Img (https://banana-img.com).
- Support for Google Nano Banana 2.1 and Nano Banana Pro models metadata.
- Pre-configured client bindings for Go, Node.js, Python, Rust, PHP, Dart, Ruby, Lua, Clojure, Swift, and JSR.
- Comprehensive prompts dataset for photorealistic image generation and conversational editing.
